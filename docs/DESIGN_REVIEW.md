## 2. 🔴 제약을 먼저 말한다 — 안 그러면 못 쓰는 시안이 온다

시안을 부탁할 때 **반드시 함께 보내는 것**:

```
· React Native(Expo)다. 웹 CSS 가 아니다
    box-shadow → iOS shadow* + Android elevation
    linear-gradient → expo-linear-gradient 를 깔아야 한다(기본 없음)
    backdrop-filter · filter · ::before/::after → 없다
· 🔴 번들 폰트를 쓰지 않는다(결정 #13). 폰트 파일이 필요한 시안은 채택 불가다
    사용자가 저장하는 책 문장의 언어를 우리가 못 정하므로 번들 폰트는 두부(□)를 만든다
· 라이트/다크 두 벌
· 현재 토큰 값(색·간격·라운드·타이포)을 그대로 붙여 준다
```

그리고 **요소마다 "에셋이냐 스타일 값이냐"를 갈라 달라고 요구한다.**
🟢 에셋 없이 되는 쪽을 우선한다 — 앱 용량과 다국어 때문에 파일을 늘리지 않는다.

## 4. 조작 함정 — `common/ASSET_GENERATION.md` §5 를 그대로 따른다

형제 프로젝트들이 이미 겪은 것들이라 **다시 밟지 않는다**:

- 🔴 **프롬프트를 타이핑하지 않는다.** 한글 IME 가 공백을 흘리고 음절을 깨뜨린다
  (`횃불` → `훃불`, 재현율 100%). `document.execCommand('insertText', …)` 로 통째 삽입한다.
  🟢 덤으로 **넣은 값을 되읽어 대조**할 수 있다 — 스크린샷으로 눈 확인하는 단계가 사라진다.
- 전송도 좌표 클릭이 아니라 `[data-testid="send-button"]` 클릭이다(입력이 길면 버튼이 밀린다).
- `ctrl+a` 는 포커스가 입력창 밖이면 **페이지 전체**를 잡는다.
- 이미지 저장의 ⬇ 는 **공유 모달**이다. 외부 공유 버튼을 누르지 않는다.
- 파일 첨부는 클릭하지 않는다(네이티브 대화상자가 뜨면 자동화가 멈춘다) — 파일 입력에 직접 넣는다.
