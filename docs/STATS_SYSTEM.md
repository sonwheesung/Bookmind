## 1. 🔴 무엇을 보여주고 무엇을 안 보여주나

기둥 5 를 데이터 층에서 지킨다. **보여주는 것과 안 보여주는 것을 먼저 못박는다.**

| 보여준다 | 안 보여준다 |
|---|---|
| 저장한 문장 수 · 책 수 · 생각 수 | 🚫 **목표 대비 진척률**(주 N권 · 월 N개) |
| 복습한 횟수 | 🚫 **밀린 개수를 크게** 띄우기(`REVIEW_SYSTEM.md` §2.2) |
| 기억률(현황으로) | 🚫 기억률에 **경고·색·목표선** |
| 연속 학습일 | 🚫 **"오늘 끊깁니다"** 류 압박 |
| 분야별(태그) 분포 | 🚫 FSRS `difficulty`·`stability`(§5 규칙 8) |

🔴 **기억률은 성취가 아니라 현황이다.** 낮다고 붉게 칠하지 않고, 높다고 칭찬하지 않는다.
숫자 옆에 형용사를 붙이지 않는다.

## 2. 🔴 파생값은 저장하지 않는다

`DATABASE.md` §4: *"기억률은 파생값이다. 저장하지 않고 매번 계산한다. 저장하면 반드시 늙는다."*

이 화면의 **모든 수는 매번 센다.** 캐시 테이블을 만들지 않는다.
⚠ 문장이 수만 건이 되면 느려질 수 있다. 그때 캐시를 논의하되, **지금 미리 만들지 않는다**
(캐시를 만드는 순간 "무엇이 진실인가"가 둘이 된다).

## 3. 지표 정의

### 3.1 저장

| 무엇 | 어떻게 |
|---|---|
| 문장 | `knowledge` 중 `deleted_at IS NULL` |
| 책 | `books` 중 `deleted_at IS NULL` |
| 생각 | `thoughts` 중 `deleted_at IS NULL` |

🔴 **tombstone 을 세지 않는다.** 백업 미리보기가 정확히 이 자리에서 틀렸다
(`EDGE_CASES.md` §8 · *"문장 2"* 라고 안내하고 화면엔 하나만 나타났다).

### 3.2 복습 · 기억률

```
복습 횟수 = review_logs 행 수            (🔴 물리 보존이라 tombstone 이 없다)
기억률    = rating != 'again' 인 행 / 전체 행
```

🔴 **분모가 0이면 기억률을 아예 안 보여준다.** `0%` 로 쓰지 않는다.
독서 진행률이 같은 결정을 이미 했다(`KNOWLEDGE_SYSTEM.md` §4.4):

> *"0%는 '안 읽었다'이지 '모른다'가 아니다."*

복습을 한 번도 안 한 사람에게 `기억률 0%` 를 보여주면 **사실이 아니고 기분만 나쁘다.**
그 자리는 비우거나 *"아직 복습한 문장이 없습니다"* 로 둔다.

⚠ `review_logs` 는 지식을 지워도 남는다(`DATABASE.md` §3). 그래서 **지운 문장의 복습도 기억률에 포함된다.**
🟢 그게 맞다. 그 복습은 실제로 일어난 일이고, 지웠다고 없던 일이 되지 않는다.

### 3.3 🔴 연속 학습일 — "오늘"을 어떻게 셀 것인가

🔄 **화면 라벨은 `연속 활동일`** 이다(2026-09-15 문구 검수). 세는 것이 저장과 복습(§4.2 의 `활동`)이라 그 이름에 맞췄고, 시험 · 학습관리 앱으로 읽히지 않게 했다. 문서의 지표 이름은 그대로 둔다.

```
활동이 있는 날 = 그 날 review_logs 가 있거나 knowledge 를 저장한 날
경계          = 기기 로컬 자정 (REVIEW_SYSTEM.md §2.1 과 같은 기준)
```

🔴 **오늘 활동이 없어도 어제까지의 연속을 끊지 않는다.**

```
어제 활동 O · 오늘 활동 X  →  연속 유지(어제까지 센 값)      ← 오늘은 아직 안 끝났다
어제 활동 X · 오늘 활동 X  →  0
오늘 활동 O                →  오늘까지 포함해서 센다
```

⚠ **이 규칙이 없으면 아침에 앱을 연 사람에게 `0일` 이라고 말하게 된다.**
어제까지 열흘을 이어온 사람이 아침 8시에 열었을 뿐인데 0 을 보는 것은 사실도 아니고
기둥 5 와도 부딪힌다. **하루가 끝나기 전에는 그 하루를 실패로 세지 않는다.**

🚫 그렇다고 *"오늘 하면 11일!"* 같은 유도 문구를 붙이지 않는다. 숫자만 둔다.

### 3.4 분야별 (태그 분포)

태그별 지식 수를 많은 순으로. `knowledge_tags` 를 세되 **양쪽 다 살아 있는 것만** 센다.
⚠ AI 가 만든 `topics` 는 태그가 아니다(`KNOWLEDGE_SYSTEM.md` §5). 섞지 않는다.

## 4. 화면

```
통계

저장          문장 128 · 책 9 · 생각 41
복습          214회 · 기억률 86%
연속 활동일    12일

분야별
  습관 24 · 심리 18 · 생산성 11 · …
```

- 빈 상태에서 **0을 강조하지 않는다**(`DESIGN_REVIEW.md` §3 채택 항목).
  신규 사용자가 `문장 0 · 책 0` 을 보면 성취 대시보드가 된다.
- 홈에는 **요약 한 줄**만 두고 상세는 이 화면이다(`KNOWLEDGE_SYSTEM.md` §7).

### 4.1 홈의 요약 한 줄과 진입점

🔄 **2026-09-14 결정 #26 으로 홈 아래 줄이 없어졌다.** 통계 진입점은 **문장 탭 위쪽의 `통계` 링크**다. 아래는 그때까지의 기록이다.

홈 아래쪽 한 줄이 그대로 진입점이다. `책 9 · 문장 128 · 연속 12일` 에서 마지막 항목을 누르면 이 화면이다.

| 상황 | 마지막 항목 |
|---|---|
| 연속일이 1 이상 | `연속 N일` |
| 연속일이 0 | `통계` |

🔴 **`연속 0일` 을 쓰지 않는다.** 그 줄의 목적은 현황을 알려주는 것이지 빈자리를 채우는 것이 아니다.
0 을 적어 두면 다음에 자연스럽게 *"오늘 하면 1일!"* 이 붙는데, 그건 기둥 5 가 막는 그것이다(§3.3).
진입점 자체는 남아야 하므로 라벨만 `통계` 로 바뀐다.

⚠ 홈의 그 줄은 원래 **책·문장이 둘 다 0이면 통째로 안 그린다**(신규 사용자에게 성취 대시보드를
만들지 않는다). 그래서 설치 직후에는 통계로 가는 길도 없는데, 그때는 볼 통계가 없으니 맞다.

### 4.2 차트 (2026-09-15)

사용자 지시 *"문장 화면의 통계 쪽 차트나 그래프나 여러가지 보여주고 싶은데 일, 주간, 월간이라던지 어떤 차트가 좋을 지 한 번 분석해서 나한테 보고해"* → 분석 보고 뒤 *"차트는 추천한 걸로 진행하면 될 것 같아"*.
참고한 곳: Anki 통계(다가올 복습 · 활동 달력 · 기간별 막대) · Readwise(활동 격자 · 주별 하이라이트) · StoryGraph(월별 막대 · 장르 막대).

```
[주] [월] [년]
‹       2026년 9월       ›
저장 12 · 복습 48 · 기억률 85%

활동          달력 칸의 진하기
저장한 문장    막대
복습          막대
────
다가올 복습    오늘부터 7일(주) · 30일(월 · 년)
────
전체          문장 · 책 · 생각 / 복습 · 기억률 / 연속 활동일
분야별        상위 5 가로 막대
책별          상위 5 가로 막대
```

| 결정 | 규칙 |
|---|---|
| 기간 | **주 · 월 · 년**. "일"은 기간이 아니라 차트 안의 단위다(하루 저장이 1~3개라 막대 하나짜리 화면이 된다). 주는 월요일에 시작한다. 고른 기간은 기기에 저장한다(`reread-stats-period` · 백업에 안 넣는다) |
| 기간 넘기기 | ‹ › · 🔴 첫 활동이 있는 기간보다 앞, 이번 기간보다 뒤로 안 간다. 기간 칩을 바꾸면 이번 기간으로 돌아온다 |
| 🔴 차트가 뜨는 조건 | 🔄 활동한 날(저장 또는 복습)이 **1일 이상**(2026-09-18 사용자 선택 · ~~7일 이상~~). 활동이 0 이면 기간 칩 · 차트 · 다가올 복습을 **아예 안 그리고** 전체 숫자만 둔다. 7일 문턱은 텅 빈 차트가 미완성으로 보이는 것을 피하려던 것인데(`DESIGN_REVIEW.md` 9/9 "책 상세의 0"), 사용자는 **차트가 가로 막대뿐인 줄** 알았다(*"차트는 가로 막대밖에 없는데 세로 차트나 이런 여러가지 차트 보여줄 거 없니?"*). 🔴 **숨겨 둔 기능은 없는 기능으로 읽힌다.** 차트별로 그 기간 합이 0 이면 그 차트만 안 그리는 규칙은 그대로다. 🚫 "N일이 쌓이면 생깁니다" 같은 안내는 여전히 없다(목표처럼 읽힌다) |
| 활동 | 저장 수 + 복습 수(§3.3 연속일과 같은 활동 정의). 진하기 0 · 1~2 · 3~5 · 6~10 · 11+(하루 복습 상한이 20 이라 그 위는 가르지 않는다). 주는 일곱 칸, 월은 달력 한 장, 년은 작은 달력 열두 장. 🚫 빈 날은 빈 칸이지 실패 표시가 아니다. 오늘 칸만 테두리 |
| 저장 · 복습 막대 | 주 7개(요일) · 월은 날짜 수(28~31) · 년 12개(달별 합 · 🔴 그 해의 날만 더한다). 🔴 **축 맨 위 값은 깔끔한 수**(1 · 2 · 5 · 10 · 20 …). 그 기간 합이 0 이면 그 차트를 안 그린다 |
| 기억률 | 기간 요약 줄의 숫자다. 🚫 **추이선을 그리지 않는다**(내려가면 성적표가 되고, 복습이 적을 때 크게 흔들린다). 그 기간 복습이 0 이면 안 쓴다(§3.2) |
| 🔴 다가올 복습 | 오늘의 복습과 **같은 규칙으로 흘린다.** 밀린 카드는 오늘로 모으고 하루 상한(20)을 넘는 것은 다음 날로 넘긴다. 날짜별 만기 수를 그대로 쌓으면 첫 막대가 홈의 "오늘의 복습"과 다른 수가 된다. 🚫 밀린 수를 따로 크게 띄우지 않는다(`REVIEW_SYSTEM.md` §2.2). 창 안 합이 0 이면 안 그린다 |
| 분야별 · 책별 | 전체 기간 상위 5 가로 막대(1위 대비 길이). 🚫 파이 차트 · 순위 번호 · 메달이 없다 |
| 색 | 글자색 한 가지의 진하기만. accent 는 선택된 기간 칩 하나다. 🚫 신호등 색 |
| 🚫 안 넣은 것 | 기억률 추이선 · 목표선 · 진척 링 · 순위 비교 · 실천 성공률(`PRACTICE_SYSTEM.md` §4) · 난이도/안정도 분포(`CLAUDE.md` §5 규칙 8) · 시간대별 · "기억 상태" 막대(등급처럼 읽힐 위험 · ChatGPT 검수 뒤 판단) · 월별 읽은 책(🔴 `finished_at` 을 아직 안 적는다) |

계산은 `features/stats/charts.ts`(순수) 하나이고 가드 ⑧~⑫ 가 경계를 잰다. 차트 라이브러리는 쓰지 않는다(View 막대 · 칸 · 부품 `BarChart` · `ActivityGrid` · `RankBars`).
⏸ ChatGPT 화면 검수 전 · 실기기 화면 확인 전.

## 5. 가드 — `npm run check:stats`

🔴 **여기서 틀리면 화면은 멀쩡한데 숫자만 조용히 틀린다.** 그게 이 프로젝트가 다섯 번 겪은 모양이다.

| 축 | 무엇을 잰다 |
|---|---|
| ① tombstone | 지운 문장·책·생각을 **안 센다** |
| ② 기억률 | `rating != 'again'` 비율이 맞나 · 🔴 **분모 0이면 `null` 을 돌려주나**(0 이 아니라) |
| ③ 지운 지식의 복습 | `review_logs` 는 남으므로 **기억률에 포함된다**(§3.2) |
| 🔴 ④ 연속일 경계 | 어제까지 이어졌고 오늘 활동이 없을 때 **연속이 유지되나** |
| ⑤ 연속일 끊김 | 하루를 건너뛰면 끊기나 · 이틀 전만 있으면 0 인가 |
| ⑥ 로컬 자정 | UTC 자정이 아니라 **기기 로컬 자정**으로 나누나 |
| ⑦ 태그 분포 | 양쪽이 살아 있는 연결만 세나 |
| ⑧ 기간 | 주는 월요일 시작 · 월말(28~31) · 윤년 · 해를 넘기는 주와 달 · 넘기기 범위(첫 활동 · 이번 기간 · 미래로 찍힌 활동) · 깨진 저장 값 → week |
| ⑨ 일별 집계 | 로컬 날짜로 접나 · 지운 문장의 저장은 빠지고 복습은 남나 · 기간 양끝 포함 · 🔴 년 막대가 다른 해를 안 섞나 · 합치기가 입력을 안 바꾸나 |
| 🔴 ⑩ 다가올 복습 | 밀린 카드가 오늘로 모이나 · 하루 상한을 넘는 수가 다음 날로 이어 넘어가나 · 창의 마지막 날은 세고 창 밖은 안 세나 · 지운 문장의 만기는 빠지나 · 깨진 날 수 · 상한을 삼키지 않나 |
| ⑪ 축 · 칸 | 깔끔한 최대값 경계(0 · 0.4 · 3→5 · 11→20 · 101→200) · 활동 단계 경계(2/3 · 5/6 · 10/11) · 음수 · NaN · Infinity · 소수를 삼키지 않나 · 달력 칸(일요일 시작 · 딱 맞는 달) |
